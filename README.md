# Static-Website
Project 1: Setup a Static Website Using Nginx
Project Tasks	Key Concepts Covered
1. Buy a domain name from a domain registrar.
2. Spin up a Ubuntu server.
3. SSH into the server and install Nginx.
4. Download HTML website files.
5. Use SCP to copy files to Nginx directory.
6. Validate using server IP address.
7. Create an A record in DNS and point to Elastic IP.
8. Use dig to check DNS records.
9. Verify site via domain.
10. Create Let's Encrypt certificate and configure Nginx.
11. Validate SSL with OpenSSL.
